在 Java 中，**重写（Override）** 和 **重载（Overload）** 是两个不同的概念，它们用于不同的目的和场景。下面详细解释这两个概念的区别，并提供示例代码。

### 1. 重写（Override）

**定义**：
重写是指子类重新定义父类中已有的方法，方法名、参数列表和返回类型必须与父类的方法完全相同。重写的主要目的是实现多态，允许子类提供特定于自己的实现。

**特点**：
- **方法名**、**参数列表** 和 **返回类型** 必须相同。
- **访问权限** 不能比父类方法更严格（例如，父类方法是 `public`，子类方法也必须是 `public`）。
- **抛出的异常** 不能比父类方法更宽泛（例如，父类方法抛出 `IOException`，子类方法不能抛出 `Exception`）。
- **使用 `@Override` 注解** 可以明确表示方法是重写父类的方法（虽然不是必须的，但推荐使用）。

**示例代码**：

```java
// 父类
class Animal {
    void makeSound() {
        System.out.println("This animal makes a sound.");
    }
}

// 子类
class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("The dog barks.");
    }
}

public class OverrideExample {
    public static void main(String[] args) {
        Animal myAnimal = new Animal();
        myAnimal.makeSound(); // 输出: This animal makes a sound.

        Animal myDog = new Dog();
        myDog.makeSound(); // 输出: The dog barks.
    }
}
```


**解释**：
- `Dog` 类重写了 `Animal` 类的 `makeSound` 方法。
- 通过多态，`myDog` 对象调用的是 `Dog` 类的 `makeSound` 方法。

### 2. 重载（Overload）

**定义**：
重载是指在同一个类中定义多个方法，它们具有相同的方法名但参数列表不同（参数类型、数量或顺序不同）。重载的主要目的是提高代码的可读性和灵活性，允许方法根据不同的参数执行不同的操作。

**特点**：
- **方法名** 必须相同。
- **参数列表** 必须不同（参数类型、数量或顺序不同）。
- **返回类型** 可以不同，但仅依赖返回类型不同不足以构成重载。
- **访问权限** 可以不同。
- **抛出的异常** 可以不同。

**示例代码**：

```java
class Calculator {
    // 重载方法 add，参数类型不同
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    // 重载方法 add，参数数量不同
    int add(int a, int b, int c) {
        return a + b + c;
    }

    // 重载方法 add，参数顺序不同
    String add(String a, String b) {
        return a + b;
    }
}

public class OverloadExample {
    public static void main(String[] args) {
        Calculator calc = new Calculator();

        System.out.println(calc.add(2, 3));          // 输出: 5
        System.out.println(calc.add(2.5, 3.5));      // 输出: 6.0
        System.out.println(calc.add(2, 3, 4));       // 输出: 9
        System.out.println(calc.add("Hello, ", "World!")); // 输出: Hello, World!
    }
}
```


**解释**：
- `Calculator` 类中定义了多个 `add` 方法，参数列表不同。
- 根据传入的参数类型和数量，调用不同的 `add` 方法。

### 重写和重载的区别

| 特性          | 重写（Override）                           | 重载（Overload）                           |
|---------------|--------------------------------------------|--------------------------------------------|
| **方法名**    | 必须相同                                   | 必须相同                                   |
| **参数列表**  | 必须相同                                   | 必须不同（类型、数量或顺序不同）           |
| **返回类型**  | 必须相同（或协变返回类型）                 | 可以不同                                   |
| **访问权限**  | 不能比父类方法更严格                       | 可以不同                                   |
| **异常**      | 不能比父类方法更宽泛                       | 可以不同                                   |
| **使用场景**  | 实现多态，子类提供特定实现                 | 提高代码的可读性和灵活性                   |
| **注解**      | 可以使用 `@Override` 注解                  | 无需注解                                   |

### 总结
- **重写（Override）**：
    - **目的**：子类提供特定于自己的实现。
    - **条件**：方法名、参数列表和返回类型必须相同。
    - **多态**：允许通过父类引用调用子类的具体实现。
- **重载（Overload）**：
    - **目的**：提高代码的可读性和灵活性。
    - **条件**：方法名相同，参数列表不同。
    - **多态**：不涉及多态，方法调用在编译时确定。
