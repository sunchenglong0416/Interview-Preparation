### 1. 封装
- **介绍**：将数据（变量）和操作数据的代码（方法）绑定成一个独立单元（对象） ，借助访问修饰符（`public`、`private`、`protected` 等）控制类成员访问权限，隐藏对象内部状态和实现细节，只暴露必要接口。
- **案例**：
```java
class Student {
    private String name;
    private int age;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }
}
```
这里`Student`类的`name`和`age`属性被设为`private`，外部不能直接访问，只能通过`public`的`getter`和`setter`方法操作，保证数据安全和一致性。

### 2. 继承
- **介绍**：是代码重用的重要机制，子类可继承父类属性和方法（除私有），还能添加自己的属性和方法 。通过`extends`关键字实现。
- **案例**：
```java
class Shape {
    public double getArea() {
        return 0;
    }
}

class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public double getArea() {
        return width * height;
    }
}

class Circle extends Shape {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
}
```
`Rectangle`和`Circle`继承自`Shape`，重写了`getArea`方法来计算各自面积，实现代码复用与扩展。

### 3. 多态
- **介绍**：允许父类类型引用指向子类对象，运行时根据实际对象类型调用对应方法。实现方式有方法重载（同一类中同名不同参数列表的方法 ）和方法重写（子类中与父类同名、参数列表相同但方法体不同的方法 ） 。
- **案例**：
```java
interface Animal {
    void speak();
}

class Dog implements Animal {
    @Override
    public void speak() {
        System.out.println("汪汪汪");
    }
}

class Cat implements Animal {
    @Override
    public void speak() {
        System.out.println("喵喵喵");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal dog = new Dog();
        Animal cat = new Cat();
        dog.speak();
        cat.speak();
    }
}
```
`Dog`和`Cat`实现`Animal`接口并重写`speak`方法，通过父类接口类型`Animal`引用调用`speak`方法时，表现出不同行为。

### 多态的好处
- **提高代码灵活性和可扩展性**：可用统一接口处理不同类型对象，降低代码耦合度。如上述动物案例，新增动物类型（如`Bird`实现`Animal`接口 ），无需大幅修改原有代码，直接使用统一`Animal`接口调用`speak`方法。
- **提高代码复用性**：能使用已有代码处理新数据类型，无需重新编写。像图形面积计算案例，新增图形子类（如三角形 ），继承`Shape`并重写`getArea`方法，就能复用计算面积的逻辑。
- **简化代码结构**：将功能相似类组织成类族，使代码结构更清晰。比如多种动物类通过`Animal`接口管理，调用方法时更简洁直观。
