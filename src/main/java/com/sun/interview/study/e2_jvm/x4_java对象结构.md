# Java 对象结构

## 一、Java 对象整体结构概述
Java 对象在内存中的结构主要由三部分构成，分别是对象头、实例数据和对齐填充。下面通过表格详细介绍各部分：

| 组成部分 | 说明 |
| --- | --- |
| 对象头（Object Header） | 包含对象的一些元数据信息，如哈希码、分代年龄、锁状态等，还包含指向对象所属类的类型指针 |
| 实例数据（Instance Data） | 存储对象的实际数据，也就是对象中定义的各种字段的值 |
| 对齐填充（Padding） | 用于保证对象的大小是 8 字节的整数倍，以提高内存访问效率 |

## 二、对象头详细结构

### （一）Mark Word
Mark Word 是对象头的一部分，用于存储对象的运行时数据，不同的锁状态下其存储内容有所不同。以下是常见状态下 32 位 JVM 中 Mark Word 的存储情况：

| 锁状态 | 25 位 | 4 位 | 1 位（是否偏向锁） | 2 位（锁标志位） |
| --- | --- | --- | --- | --- |
| 无锁状态 | 对象的哈希码 | 对象分代年龄 | 0 | 01 |
| 偏向锁 | 线程 ID、Epoch | 对象分代年龄 | 1 | 01 |
| 轻量级锁 | 指向栈中锁记录的指针 | 无 | 无 | 00 |
| 重量级锁 | 指向重量级锁的指针 | 无 | 无 | 10 |
| GC 标记 | 无 | 无 | 无 | 11 |

### （二）类型指针（Class Pointer）
类型指针指向对象所属类的元数据信息，JVM 通过这个指针来确定该对象是哪个类的实例。

| 名称 | 说明 |
| --- | --- |
| 类型指针 | 指向对象所属类的元数据，用于在运行时确定对象的类型 |

### （三）数组长度（仅数组对象有）
如果对象是数组类型，对象头中还会包含数组的长度信息。

| 名称 | 说明 |
| --- | --- |
| 数组长度 | 对于数组对象，记录数组的元素个数 |

## 三、实例数据结构
实例数据是对象真正存储数据的地方，它包含了对象的各个字段。

| 字段类型 | 说明 |
| --- | --- |
| 基本数据类型字段 | 如 int、long、boolean 等，直接存储对应的值 |
| 引用类型字段 | 存储对象的引用，指向其他对象在内存中的地址 |

## 四、对齐填充说明
由于 JVM 要求对象的大小必须是 8 字节的整数倍，当对象头和实例数据的总大小不是 8 字节的整数倍时，就需要进行对齐填充，以满足这一要求。

| 名称 | 作用 |
| --- | --- |
| 对齐填充 | 保证对象大小是 8 字节的整数倍，提高内存访问效率 |
