
### 1. 队列（Queue）

#### 1.1 定义

**队列**是一种先进先出（First-In-First-Out, FIFO）的数据结构。元素从队列的一端（尾部）进入，从另一端（头部）离开。队列的基本操作包括入队（enqueue）和出队（dequeue）。

#### 1.2 主要接口和实现类

**主要接口**：
- **`java.util.Queue`**：定义了队列的基本操作。

**主要实现类**：
- **`java.util.LinkedList`**：使用双向链表实现队列。
- **`java.util.PriorityQueue`**：使用优先队列实现队列，元素按优先级排序。
- **`java.util.ArrayDeque`**：使用数组实现双端队列，可以作为队列使用。
- **`java.util.concurrent.ConcurrentLinkedQueue`**：线程安全的无界队列。
- **`java.util.concurrent.PriorityBlockingQueue`**：线程安全的优先队列。
- **`java.util.concurrent.ArrayBlockingQueue`**：线程安全的有界队列。
- **`java.util.concurrent.LinkedBlockingQueue`**：线程安全的无界队列。
- **`java.util.concurrent.DelayQueue`**：线程安全的延迟队列，元素在指定时间后才能被取出。
- **`java.util.concurrent.SynchronousQueue`**：线程安全的同步队列，不存储元素，直接进行线程间的元素传递。

#### 1.3 应用场景

- **任务调度**：操作系统中的任务调度，如进程调度。
- **打印队列**：打印机任务的管理。
- **消息队列**：分布式系统中的消息传递。
- **广度优先搜索（BFS）**：图的遍历算法。
- **缓存**：缓存系统中的请求管理。

#### 1.4 代码示例

**使用 `LinkedList` 实现队列**：
```java
import java.util.LinkedList;
import java.util.Queue;

public class QueueExample {
    public static void main(String[] args) {
        Queue<String> queue = new LinkedList<>();

        // 入队操作
        queue.add("Element 1");
        queue.add("Element 2");
        queue.add("Element 3");

        System.out.println("Queue: " + queue);

        // 出队操作
        String element = queue.poll();
        System.out.println("Removed Element: " + element);
        System.out.println("Queue after removal: " + queue);

        // 查看队头元素
        String head = queue.peek();
        System.out.println("Head of Queue: " + head);
    }
}
```


**输出**：
```
Queue: [Element 1, Element 2, Element 3]
Removed Element: Element 1
Queue after removal: [Element 2, Element 3]
Head of Queue: Element 2
```


**解释**：
- **创建队列**：使用 `LinkedList` 实现队列。
- **入队操作**：使用 `add` 方法将元素添加到队尾。
- **出队操作**：使用 `poll` 方法移除并返回队头元素。
- **查看队头元素**：使用 `peek` 方法查看队头元素但不移除。

### 2. 栈（Stack）

#### 2.1 定义

**栈**是一种后进先出（Last-In-First-Out, LIFO）的数据结构。元素从栈的一端（栈顶）进入，从同一端离开。栈的基本操作包括入栈（push）和出栈（pop）。

#### 2.2 主要接口和实现类

**主要接口**：
- **`java.util.Deque`**：定义了双端队列的基本操作，可以作为栈使用。

**主要实现类**：
- **`java.util.Stack`**：使用数组实现栈（不推荐使用，推荐使用 `Deque`）。
- **`java.util.ArrayDeque`**：使用数组实现双端队列，可以作为栈使用。
- **`java.util.concurrent.ConcurrentLinkedDeque`**：线程安全的双端队列，可以作为栈使用。

#### 2.3 应用场景

- **函数调用**：函数调用的管理，如递归调用。
- **表达式求值**：中缀表达式转后缀表达式、后缀表达式的求值。
- **撤销操作**：软件中的撤销操作，如文本编辑器。
- **深度优先搜索（DFS）**：图的遍历算法。
- **括号匹配**：检查括号是否匹配。

#### 2.4 代码示例

**使用 `ArrayDeque` 实现栈**：
```java
import java.util.ArrayDeque;
import java.util.Deque;

public class StackExample {
    public static void main(String[] args) {
        Deque<String> stack = new ArrayDeque<>();

        // 入栈操作
        stack.push("Element 1");
        stack.push("Element 2");
        stack.push("Element 3");

        System.out.println("Stack: " + stack);

        // 出栈操作
        String element = stack.pop();
        System.out.println("Removed Element: " + element);
        System.out.println("Stack after removal: " + stack);

        // 查看栈顶元素
        String top = stack.peek();
        System.out.println("Top of Stack: " + top);
    }
}
```


**输出**：
```
Stack: [Element 3, Element 2, Element 1]
Removed Element: Element 3
Stack after removal: [Element 2, Element 1]
Top of Stack: Element 2
```


**解释**：
- **创建栈**：使用 `ArrayDeque` 实现栈。
- **入栈操作**：使用 `push` 方法将元素添加到栈顶。
- **出栈操作**：使用 `pop` 方法移除并返回栈顶元素。
- **查看栈顶元素**：使用 `peek` 方法查看栈顶元素但不移除。

### 1. ArrayBlockingQueue

#### 1.1 定义

**ArrayBlockingQueue** 是一个基于数组实现的有界阻塞队列。它具有固定容量，并且在队列满时，入队操作会被阻塞；在队列空时，出队操作也会被阻塞。

#### 1.2 主要特点

- **有界队列**：容量固定，需要在创建时指定。
- **阻塞队列**：在队列满时，入队操作会被阻塞；在队列空时，出队操作会被阻塞。
- **线程安全**：内部使用锁机制（ReentrantLock）来保证线程安全。
- **公平性**：可以指定是否使用公平锁。

#### 1.3 适用场景

- **生产者-消费者模型**：当需要固定大小的缓冲区时。
- **资源受限的场景**：当需要限制队列中元素的最大数量时。
- **需要公平性保证的场景**：当需要保证线程按照请求的顺序访问队列时。

#### 1.4 代码示例

```java
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.BlockingQueue;

public class ArrayBlockingQueueExample {
    public static void main(String[] args) {
        // 创建一个容量为 3 的 ArrayBlockingQueue
        BlockingQueue<String> queue = new ArrayBlockingQueue<>(3);

        // 生产者线程
        Thread producer = new Thread(() -> {
            try {
                queue.put("Element 1");
                System.out.println("Produced: Element 1");
                queue.put("Element 2");
                System.out.println("Produced: Element 2");
                queue.put("Element 3");
                System.out.println("Produced: Element 3");
                // 尝试添加第四个元素，队列已满，会阻塞
                queue.put("Element 4");
                System.out.println("Produced: Element 4");
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        // 消费者线程
        Thread consumer = new Thread(() -> {
            try {
                // 消费元素
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        producer.start();
        consumer.start();
    }
}
```


**输出**：
```
Produced: Element 1
Produced: Element 2
Produced: Element 3
Consumed: Element 1
Consumed: Element 2
Consumed: Element 3
Produced: Element 4
Consumed: Element 4
```


**解释**：
- **创建队列**：创建一个容量为 3 的 `ArrayBlockingQueue`。
- **生产者线程**：尝试添加元素到队列中，当队列满时，`put` 方法会阻塞。
- **消费者线程**：从队列中取出元素，当队列空时，`take` 方法会阻塞。

### 2. LinkedBlockingQueue

#### 2.1 定义

**LinkedBlockingQueue** 是一个基于链表实现的可选有界阻塞队列。默认情况下，它是一个无界队列，但也可以通过构造函数指定容量。

#### 2.2 主要特点

- **可选有界队列**：默认无界，但可以指定容量。
- **阻塞队列**：在队列满时，入队操作会被阻塞；在队列空时，出队操作也会被阻塞。
- **线程安全**：内部使用两个锁（一个用于入队，一个用于出队）来保证线程安全。
- **公平性**：默认使用非公平锁，但也可以指定使用公平锁。

#### 2.3 适用场景

- **生产者-消费者模型**：当需要灵活调整队列大小时。
- **无界队列**：当不需要限制队列中元素的最大数量时。
- **高并发场景**：由于使用两个锁，可以提高并发性能。

#### 2.4 代码示例

```java
import java.util.concurrent.LinkedBlockingQueue;
import java.util.concurrent.BlockingQueue;

public class LinkedBlockingQueueExample {
    public static void main(String[] args) {
        // 创建一个无界 LinkedBlockingQueue
        BlockingQueue<String> queue = new LinkedBlockingQueue<>();

        // 生产者线程
        Thread producer = new Thread(() -> {
            try {
                queue.put("Element 1");
                System.out.println("Produced: Element 1");
                queue.put("Element 2");
                System.out.println("Produced: Element 2");
                queue.put("Element 3");
                System.out.println("Produced: Element 3");
                // 继续添加元素，不会阻塞
                queue.put("Element 4");
                System.out.println("Produced: Element 4");
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        // 消费者线程
        Thread consumer = new Thread(() -> {
            try {
                // 消费元素
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
                System.out.println("Consumed: " + queue.take());
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        producer.start();
        consumer.start();
    }
}
```


**输出**：
```
Produced: Element 1
Produced: Element 2
Produced: Element 3
Produced: Element 4
Consumed: Element 1
Consumed: Element 2
Consumed: Element 3
Consumed: Element 4
```


**解释**：
- **创建队列**：创建一个无界的 `LinkedBlockingQueue`。
- **生产者线程**：添加元素到队列中，不会阻塞。
- **消费者线程**：从队列中取出元素，当队列空时，`take` 方法会阻塞。

### 3. ArrayBlockingQueue 和 LinkedBlockingQueue 的详细对比

| 特性          | ArrayBlockingQueue                                | LinkedBlockingQueue                                |
|---------------|---------------------------------------------------|----------------------------------------------------|
| **实现方式**  | 基于数组实现                                      | 基于链表实现                                       |
| **容量**      | 固定容量，创建时指定                              | 可选有界，创建时可以指定容量，不指定则为无界         |
| **锁机制**    | 使用单个 ReentrantLock，内部使用条件变量            | 使用两个锁（一个用于入队，一个用于出队），提高并发性能 |
| **公平性**    | 可以指定是否使用公平锁                            | 默认使用非公平锁，也可以指定使用公平锁               |
| **内存占用**  | 固定大小的数组，内存占用较为固定                    | 动态链表，内存占用随元素数量变化                     |
| **适用场景**  | 需要固定大小的缓冲区，且需要保证公平性时            | 需要灵活调整队列大小，且需要高并发性能时             |
