# spring 过滤器


责任链模式是一种行为设计模式，它允许你将请求沿着处理者链进行发送。当请求到达链中的某个处理者时，该处理者会决定是处理请求还是将其传递给链中的下一个处理者。以下是其详细介绍、应用场景及示例说明：

### 定义与概念
责任链模式通过将处理者对象连成一条链，并让请求在这条链上传递，直到有处理者能够处理该请求为止。这样可以将请求的发送者和接收者解耦，使得系统更加灵活和可维护。

### 结构与角色
- **抽象处理者（Handler）**：定义了处理请求的抽象方法，并持有对下一个处理者的引用，以便将请求传递下去。
- **具体处理者（Concrete Handler）**：实现了抽象处理者定义的处理方法，根据自身的逻辑来决定是否处理请求，如果不能处理则将请求传递给下一个处理者。
- **客户端（Client）**：创建请求并将其发送到责任链的起始端。

### 应用场景
- **审批流程**：如请假审批、费用报销审批等。不同级别的审批者构成责任链，根据审批金额或其他条件，请求在链上传递，直到被批准或拒绝。
- **拦截器与过滤器**：在Web应用中，拦截器或过滤器链可以对请求进行预处理和后处理。例如，对请求进行权限验证、日志记录、数据加密等操作。
- **事件处理**：在图形界面应用中，当用户触发某个事件（如鼠标点击、键盘输入等）时，可能需要多个组件来处理该事件。可以将这些组件构成责任链，依次处理事件。

### 示例说明
以员工请假审批为例，假设员工请假需要经过组长、部门经理和总经理三级审批。
1. **定义抽象处理者**：
```java
abstract class Approver {
    protected Approver successor;

    public void setSuccessor(Approver successor) {
        this.successor = successor;
    }

    abstract public void processRequest(LeaveRequest request);
}
```
2. **定义具体处理者**：
```java
class TeamLeader extends Approver {
    @Override
    public void processRequest(LeaveRequest request) {
        if (request.getDays() <= 2) {
            System.out.println("Team leader approved the leave request.");
        } else if (successor != null) {
            successor.processRequest(request);
        }
    }
}

class DepartmentManager extends Approver {
    @Override
    public void processRequest(LeaveRequest request) {
        if (request.getDays() <= 5) {
            System.out.println("Department manager approved the leave request.");
        } else if (successor != null) {
            successor.processRequest(request);
        }
    }
}

class GeneralManager extends Approver {
    @Override
    public void processRequest(LeaveRequest request) {
        System.out.println("General manager approved the leave request.");
    }
}
```
3. **定义请求类**：
```java
class LeaveRequest {
    private int days;

    public LeaveRequest(int days) {
        this.days = days;
    }

    public int getDays() {
        return days;
    }
}
```
4. **客户端使用**：
```java
public class Main {
    public static void main(String[] args) {
        // 创建处理者对象
        TeamLeader teamLeader = new TeamLeader();
        DepartmentManager departmentManager = new DepartmentManager();
        GeneralManager generalManager = new GeneralManager();

        // 设置责任链
        teamLeader.setSuccessor(departmentManager);
        departmentManager.setSuccessor(generalManager);

        // 创建请假请求并提交审批
        LeaveRequest request1 = new LeaveRequest(1);
        teamLeader.processRequest(request1);

        LeaveRequest request2 = new LeaveRequest(3);
        teamLeader.processRequest(request2);

        LeaveRequest request3 = new LeaveRequest(7);
        teamLeader.processRequest(request3);
    }
}
```
在上述示例中，`Approver`是抽象处理者，`TeamLeader`、`DepartmentManager`和`GeneralManager`是具体处理者，
`LeaveRequest`是请求类。客户端创建责任链并提交请假请求，请求会根据请假天数在责任链上传递，直到被相应的处理者批准。
